# 异常案例库

> 本案例库沉淀历史异常申请的审核结论与依据，供人工复核参考。
> 案例中的敏感信息已脱敏（信用代码掩码、金额脱敏）。

## 一、强规则 FAIL 案例

### 案例 1：营业执照已注销

| 项目 | 内容 |
|---|---|
| 产品 | 普惠小微经营贷（AP） |
| 触发规则 | AP-H01 营业执照存续 |
| 问题描述 | 营业执照登记状态为「注销」 |
| 审核结论 | 拒绝 |
| 依据 | 营业执照状态需为存续/在营/开业，已注销直接拒绝 |
| 处置建议 | 不接受申请，建议企业重新注册后再申请 |

### 案例 2：成立年限不足

| 项目 | 内容 |
|---|---|
| 产品 | 普惠小微经营贷（AP） |
| 触发规则 | AP-H02 成立年限 ≥ 2 年 |
| 问题描述 | 企业成立日期为 2025-06-15，申请日为 2026-11-07，成立 17 个月 |
| 审核结论 | 拒绝 |
| 依据 | 成立不足 24 个月的企业不接受经营贷 |
| 处置建议 | 建议申请小微快贷（AK，成立 ≥ 1 年即可） |

### 案例 3：征信授权书过期

| 项目 | 内容 |
|---|---|
| 产品 | 小微快贷（AK） |
| 触发规则 | AK-H04 征信授权书有效 |
| 问题描述 | 授权书签署日期为 2026-03-01，申请日为 2026-11-07，超过 6 个月 |
| 审核结论 | 拒绝 |
| 依据 | 授权书签署日期需在近 6 个月内 |
| 处置建议 | 需重新签署征信授权书 |

### 案例 4：抵押物材料缺失

| 项目 | 内容 |
|---|---|
| 产品 | 经营性抵押贷（AJ） |
| 触发规则 | AJ-H04 抵押物材料已提供 |
| 问题描述 | 未上传任何抵押物证明材料 |
| 审核结论 | 拒绝 |
| 依据 | 经营性抵押贷需提供抵押合同/评估报告/房产证等 |
| 处置建议 | 补充抵押物证明材料后重新申请 |

## 二、一致性 HIGH FAIL 案例

### 案例 5：企业名称不一致

| 项目 | 内容 |
|---|---|
| 校验项 | C1 企业名称一致性 |
| 问题描述 | 营业执照为「XX 科技有限公司」，银行流水户名为「XX 科技有限责任公司」 |
| 审核结论 | 关注 |
| 依据 | 各来源企业全称不一致 |
| 处置建议 | 以营业执照为准，核实银行流水户名是否为同一主体 |

### 案例 6：资产负债表不平

| 项目 | 内容 |
|---|---|
| 校验项 | C15 资产负债表恒等式 |
| 问题描述 | 资产总计 1,200 万，负债合计 800 万，所有者权益 350 万，差额 50 万 |
| 审核结论 | 关注 |
| 依据 | 资产 ≠ 负债 + 所有者权益 |
| 处置建议 | 核实财务报表数据，可能为 OCR 识别错误或报表本身不平 |

### 案例 7：银行流水勾稽不平

| 项目 | 内容 |
|---|---|
| 校验项 | C14 银行流水勾稽平衡 |
| 问题描述 | 期初 100 万 + 收入 50 万 - 支出 30 万 = 120 万，但期末为 115 万 |
| 审核结论 | 关注 |
| 依据 | 期初+收入-支出 ≠ 期末 |
| 处置建议 | 核实原始对账单，检查是否有遗漏交易或 OCR 识别错误 |

## 三、弱规则 FAIL 案例

### 案例 8：资产负债率过高

| 项目 | 内容 |
|---|---|
| 产品 | 普惠小微经营贷（AP） |
| 触发规则 | AP-S02 资产负债率 ≤ 70% |
| 问题描述 | 负债合计 850 万，资产总计 1,000 万，负债率 85% |
| 审核结论 | 弱规则 FAIL（扣 14 分） |
| 依据 | 负债率超过 70% 阈值 |
| 处置建议 | 提示偿债能力不足，建议降额或补充担保 |

### 案例 9：流水进账偏低

| 项目 | 内容 |
|---|---|
| 产品 | 普惠小微经营贷（AP） |
| 触发规则 | AP-S01 流水进账 ≥ 年营收 70% |
| 问题描述 | 12 月流水贷方合计 300 万，年营收 500 万，比例 60% |
| 审核结论 | 弱规则 FAIL（扣 14 分） |
| 依据 | 流水进账与营收差异过大 |
| 处置建议 | 提示收入虚增风险，需核实实际经营规模 |

## 四、材料完整性案例

### 案例 10：财务报表缺表现金流量表

| 项目 | 内容 |
|---|---|
| 产品 | 普惠小微经营贷（AP） |

### 案例 11：银行流水覆盖不足

| 项目 | 内容 |
|---|---|
| 产品 | 普惠小微经营贷（AP） |
| 问题描述 | 银行流水仅覆盖 8 个月（2026-01 至 2026-08） |

| 依据 | AP 产品要求流水覆盖 ≥ 12 个月 |
