# 信贷政策总则

## 一、适用范围

本政策适用于本行小微企业授信业务的智能预审环节，覆盖以下四款贷款产品：

| 产品代码 | 产品名称 | 客群定位 |
|---|---|---|
| AP | 普惠小微经营贷 | 成立满 2 年、经营稳定的小微企业 |
| AK | 小微快贷 | 轻资料、快速审批的小微企业 |
| AJ | 经营性抵押贷 | 能提供抵押物的小微企业 |
| AE | 科技e贷 | 科技型中小企业（高新技术/专精特新） |

## 二、基本原则

1. **强规则一票否决**：强规则（hard）任一 FAIL 直接拒绝，不进入打分环节；
2. **弱规则影响评分**：弱规则（soft）FAIL 不拦截，但影响最终得分与等级；
3. **材料完整性优先**：缺件或内容不可读时，转人工补件，不执行规则匹配；
4. **一致性高风险关注**：一致性校验出现 HIGH 级别 FAIL 时，结论降级为「关注」；
5. **结论优先级**：拒绝 > 转人工 > 关注 > 通过。

## 三、术语定义

| 术语 | 定义 |
|---|---|
| 强规则（hard） | 硬性准入门槛，FAIL 直接拒绝 |
| 弱规则（soft） | 评分项，FAIL 影响得分但不直接拒绝 |
| 完整性 | 必交材料齐全且内容可读 |
| 一致性 | 跨材料的主体信息、期间、金额勾稽一致 |
| 三态判定 | pass / fail / uncertain，字段缺失时为 uncertain |
| 严重度 | 一致性校验的风险等级：high / medium / low |

## 四、申请编号规则

申请编号 = 贷款类型前缀 + 8 位独立递增序号，不同贷款类型序号各自独立计数：

| 产品 | 前缀 | 示例 |

| 普惠小微经营贷 | AP | AP00000001 |
| 小微快贷 | AK | AK00000001 |
| 经营性抵押贷 | AJ | AJ00000001 |
