# 一致性校验规则

## 一、校验概述

一致性校验用于核验跨材料的主体信息、期间与金额勾稽是否一致，采用**三态判定**：

| 状态 | 编码 | 含义 |
|---|---|---|
| 通过 | pass | 各来源取值一致 |
| 不通过 | fail | 各来源取值不一致 |
| 存疑 | uncertain | 关键字段缺失，无法比对，转人工核验 |

## 二、严重度分级

| 严重度 | 编码 | 影响 |
|---|---|---|
| 高 | high | FAIL 时结论降级为「关注」 |
| 中 | medium | FAIL 时记录问题，不直接降级 |
| 低 | low | FAIL 时记录问题，不直接降级 |

> 仅 high 级不一致会标记整体一致性不通过（`is_consistent=false`）。

## 三、P1 核心校验项

### C1 企业名称一致性

| 项目 | 内容 |
|---|---|
| 严重度 | high |
| 校验逻辑 | 营业执照、银行流水、财务报表、纳税申报表、征信授权书中的企业名称，归一化（去空白与标点）后必须唯一 |
| 数据来源 | application.company_name + 各材料 OCR 抽取的企业名称 |
| FAIL 处置 | 各来源企业全称不一致，请以营业执照为准核实 |
| uncertain 条件 | 可比对的来源 < 2 个 |

### C2 统一社会信用代码一致性

| 项目 | 内容 |
|---|---|
| 严重度 | high |
| 校验逻辑 | 营业执照、征信授权书、纳税申报表中的统一社会信用代码（18 位）必须一致 |
| 数据来源 | application.credit_code + 各材料 OCR 抽取的信用代码 |
| FAIL 处置 | 各来源统一社会信用代码不一致，请核实原件 |
| uncertain 条件 | 可比对的来源 < 2 个 |
| 备注 | 纳税人识别号仅在 18 位格式时参与比对 |

### C5 银行流水期间连续性

| 项目 | 内容 |
|---|---|
| 严重度 | medium |
| 校验逻辑 | 多份银行流水的交易期间必须连续覆盖，无断月 |
| 数据来源 | 银行流水 OCR 抽取的统计期间或交易日期 |
| FAIL 处置 | 流水期间不连续，列出缺失月份，需补充流水 |
| uncertain 条件 | 无银行流水或期间无法识别 |

### C6 财务报表年度与纳税申报所属年度一致性

| 项目 | 内容 |
|---|---|
| 严重度 | medium |
| 校验逻辑 | 财务报表所属年度必须与纳税申报表所属年度一致 |
| 数据来源 | 财务报表 OCR 抽取的年度 + 纳税申报表 OCR 抽取的年度 |
| FAIL 处置 | 财务报表年度与纳税申报所属年度不一致 |
| uncertain 条件 | 财务报表或纳税申报表年度缺失 |

### C7 征信授权时效

| 项目 | 内容 |
|---|---|
| 严重度 | high |
| 校验逻辑 | 征信授权书签署日期至申请提交日 ≤ 6 个月，且授权有效期未过 |
| 数据来源 | 征信授权书 OCR 抽取的签署日期、有效期至 + application.created_at |
| FAIL 处置 | 授权书签署超过 6 个月或授权期限已过，需重新签署 |
| uncertain 条件 | 无征信授权书或签署日期缺失 |

### C9 材料日期时效

| 项目 | 内容 |
|---|---|
| 严重度 | high |
| 校验逻辑 | 所有材料的所属日期不得晚于申请提交日期 + 1 天 |
| 数据来源 | 银行流水期间结束日、财务报表期间结束日、纳税申报表期间结束日、征信授权书签署日期 |
| FAIL 处置 | 材料日期晚于申请提交日期，列出异常来源 |
| uncertain 条件 | 无材料日期可识别 |

### C14 银行流水勾稽平衡

| 项目 | 内容 |
|---|---|
| 严重度 | high |
| 校验逻辑 | 每份银行流水需满足：期初余额 + 本月收入 - 本月支出 = 期末余额（容差 1 元） |
| 数据来源 | 银行流水 OCR 抽取的期初余额、本月合计（收入、支出）、期末余额 |
| FAIL 处置 | 流水借贷与余额不平，需核实原始对账单 |
| uncertain 条件 | 期初/收入/支出/期末任一缺失 |

### C15 资产负债表恒等式

| 项目 | 内容 |
|---|---|
| 严重度 | high |
| 校验逻辑 | 资产总计 = 负债合计 + 所有者权益合计（容差 1 元） |
| 数据来源 | 财务报表 OCR 抽取的资产总计、负债合计、所有者权益合计 |
| FAIL 处置 | 资产与负债+所有者权益差额过大，报表不平 |
| uncertain 条件 | 资产/负债/所有者权益任一缺失 |

## 四、一致性整体判定

```
is_consistent = 不存在 (status == fail AND severity == high) 的校验项
```

- 存在任一 high 级 FAIL → 整体一致性不通过，结论降级为「关注」；
- 仅 medium/low 级 FAIL → 整体一致性通过，记录问题项供人工参考；
- uncertain 项不影响整体一致性判定，但提示转人工核验。
