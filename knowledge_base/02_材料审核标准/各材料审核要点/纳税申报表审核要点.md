# 纳税申报表审核要点

## 一、必填字段

| 字段名 | 说明 | 抽取方式 |
|---|---|---|
| 纳税人名称 | 纳税主体名称 | 关键字「纳税人名称」后匹配 |
| 纳税人识别号 | 15-20 位编码 | 关键字「纳税人识别号」后匹配 |
| 税款所属年度 | 申报覆盖年度 | 从期间表达式中提取年份 |
| 营业收入 | 金额 | 关键字「营业收入」后匹配金额 |
| 利润总额 | 金额 | 关键字「利润总额」后匹配金额 |
| 期间结束日 | YYYY-MM-DD | 关键字「至」后匹配中文日期 |

## 二、字段校验规则

### 2.1 纳税人识别号格式

- 15-20 位字母数字组合；
- 仅当为 18 位格式时参与统一社会信用代码一致性校验（C2）。

### 2.2 研发费用加计扣除识别（AE-S03）

- 文本中是否包含「研发费用加计扣除」或体现高新技术企业优惠税率；
- 用于科技e贷的弱规则校验。

### 2.3 重大欠税识别

- 文本中是否存在重大欠税记录；
- 所有产品的弱规则均校验此项（AP-S06 / AK-S05 / AJ-S06 / AE-S06）。

## 三、参与的一致性校验

| 校验项 | 校验内容 |
|---|---|
| C1 企业名称一致性 | 纳税人名称与申请信息、其他材料比对 |
| C2 统一社会信用代码一致性 | 纳税人识别号（18 位时）与营业执照、征信授权书比对 |
| C6 财报与纳税年度一致性 | 纳税申报所属年度与财务报表年度比对 |
| C9 材料日期时效 | 纳税申报期间结束日不得晚于申请提交日 |

## 四、参与的准入规则

| 产品 | 规则编号 | 规则名称 |
|---|---|---|
| AP | AP-S06 | 纳税申报无重大欠税 |
| AK | AK-S05 | 纳税申报无重大欠税 |
| AJ | AJ-S06 | 纳税申报无重大欠税 |
| AE | AE-S03 | 研发费用加计扣除或高新技术企业资格有效 |
| AE | AE-S06 | 纳税申报无重大欠税 |

## 五、常见问题与处置

| 问题 | 处置方式 |
|---|---|
| 纳税人识别号为 15 位旧格式 | 不参与信用代码一致性校验，仅记录 |
| 增值税与所得税申报表分开上传 | 合并所有纳税申报表类材料的文本 |
| 「营业收入」在多个表中出现 | 取第一个非空值 |
| 无法识别税款所属年度 | C6 标记为 uncertain，转人工核验 |
