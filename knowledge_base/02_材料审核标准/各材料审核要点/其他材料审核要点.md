# 其他材料审核要点

## 一、材料范围

「其他」类材料包含但不限于：

### 1.1 抵押物证明（经营性抵押贷 AJ 必交）

| 材料类型 | 识别关键词 | 抽取字段 |
|---|---|---|
| 抵押合同 | 「抵押合同」「抵押权人」「抵押人」 | 抵押物描述、抵押金额 |
| 抵押物评估报告 | 「评估报告」「评估价值」「评估值」 | 评估价值（万元/元） |
| 房产证 | 「房产证」「房屋所有权证」「不动产」 | 房屋坐落、面积 |
| 租赁合同 | 「租赁合同」「出租人」「承租人」 | 租赁面积、租金 |

### 1.2 科技资质证书（科技e贷 AE 必交）

| 材料类型 | 识别关键词 | 抽取字段 |
|---|---|---|
| 高新技术企业证书 | 「高新技术企业」 | 证书编号、有效期 |
| 专精特新证书 | 「专精特新」 | 证书编号、认定机构 |
| 科技型中小企业证书 | 「科技型中小企业」 | 证书编号、入库编号 |
| 知识产权证书 | 「发明专利」「软件著作权」「实用新型」「商标」 | 知识产权类型、数量 |

## 二、字段校验规则

### 2.1 抵押物评估价值识别（AJ-S03）

- 搜索关键词：「评估价值」「评估值」「抵押价值」「评估金额」；
- 匹配金额后，若包含「万元」则 ×10000 转换为元；
- 用于计算抵押率：申请金额 / 抵押物评估价值 ≤ 70%。

### 2.2 科技资质识别（AE-H03）

- 检查文本中是否包含以下任一关键词：
  - 「高新技术企业」「专精特新」「知识产权」「发明专利」「软件著作权」「科技型中小企业」；
- 存在任一即视为具备科技资质。

### 2.3 知识产权数量识别（AE-S07）

- 统计以下关键词出现次数：「发明专利」「软件著作权」「实用新型」「商标」；
- ≥ 1 项即通过弱规则。

## 三、参与的准入规则

| 产品 | 规则编号 | 规则名称 |
|---|---|---|
| AJ | AJ-H04 | 抵押物材料已提供（强规则） |
| AJ | AJ-S03 | 申请金额 ≤ 抵押物评估价值 × 70% |
| AE | AE-H03 | 具备高新技术或专精特新资质（强规则） |
| AE | AE-S07 | 知识产权数量 ≥ 1 项 |

## 四、常见问题与处置

| 问题 | 处置方式 |
|---|---|
| 评估报告中评估价值单位不统一 | 识别「万元」关键字自动转换，否则按元处理 |
| 科技资质证书为复印件且关键字模糊 | 无法识别 → 强规则 FAIL，拒绝 |
| 多份知识产权证书 | 合并统计数量，取最大值 |
| 抵押物材料无法识别评估价值 | AJ-S03 标记为 uncertain，不影响强规则判定 |
