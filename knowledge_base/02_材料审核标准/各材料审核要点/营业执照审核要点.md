# 营业执照审核要点

## 一、必填字段

| 字段名 | 说明 | 抽取方式 |
|---|---|---|
| 企业名称 | 工商注册全称 | 关键字「名称」后匹配公司名称 |
| 统一社会信用代码 | 18 位编码 | 正则 `[0-9A-Z]{18}` + GB 32100 校验 |
| 法定代表人 | 自然人姓名 | 关键字「法定代表人」后匹配中文姓名 |
| 成立日期 | YYYY-MM-DD | 关键字「成立日期」后匹配中文日期 |
| 登记状态 | 存续/在营/开业等 | 关键字匹配 |
| 营业期限 | 起止日期 | 关键字「营业期限」后匹配日期范围 |

## 二、字段校验规则

### 2.1 统一社会信用代码格式校验（GB 32100）

- 必须为 18 位；
- 字符集：`0123456789ABCDEFGHJKLMNPQRTUWXY`（不含 I、O、Z、S、V）；
- 校验算法：前 17 位按加权因子 `(1,3,9,27,19,26,16,17,20,29,25,13,8,24,10,30,28)` 加权求和，`31 - sum % 31` 即为校验位序号（等于 31 时取 0）。

### 2.2 成立年限校验

- 成立年限 = 申请日期 - 成立日期（按月计算）；
- 普惠小微经营贷（AP）：≥ 24 个月（硬规则）；
- 其他产品：≥ 12 个月（硬规则）。

### 2.3 登记状态校验

- 必须 ∈ {存续, 在营, 开业}；
- 已吊销、注销、迁出、非正常 → 拒绝；
- 未直接标注登记状态时，按营业期限兜底推断：营业期限未届满 → 存续。

## 三、参与的一致性校验

| 校验项 | 校验内容 |
|---|---|
| C1 企业名称一致性 | 与申请信息、其他材料的企业名称比对 |
| C2 统一社会信用代码一致性 | 与征信授权书、纳税申报表的信用代码比对 |

## 四、常见问题与处置

| 问题 | 处置方式 |
|---|---|
| OCR 将「存续」识别为「存结」等形近字 | 按营业期限兜底推断登记状态 |
| 信用代码识别缺失 | 用申请信息中的 credit_code 兜底 |
| 成立日期格式异常（如「2019年8月28日」无零填充） | 正则兼容 `\d{1,2}` 月日 |
| 营业执照为复印件且信息模糊 | OCR 文本为空 → 标记不可读，需重传 |
