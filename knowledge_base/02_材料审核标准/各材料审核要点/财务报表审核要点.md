# 财务报表审核要点

## 一、必填字段

| 字段名 | 说明 | 抽取方式 |
|---|---|---|
| 报表名称 | 报表首页标题 | 取文本第一行非空内容 |
| 所属年度 | 报表覆盖年度 | 从期间表达式中提取年份 |
| 是否含资产负债表 | 布尔值 | 文本中是否包含「资产负债表」 |
| 营业收入 | 金额 | 关键字「营业收入」后匹配金额 |
| 利润总额 | 金额 | 关键字「利润总额」后匹配金额 |
| 资产总计 | 金额 | 关键字「资产总计」后匹配金额 |
| 负债合计 | 金额 | 关键字「负债合计」后匹配金额 |
| 所有者权益合计 | 金额 | 关键字「所有者权益合计」后匹配金额 |
| 期间结束日 | YYYY-MM-DD | 关键字「至」后匹配中文日期 |

## 二、字段校验规则

### 2.1 三表齐全校验

财务报表必须同时包含：
- 资产负债表
- 利润表
- 现金流量表

缺失任一表则完整性校验不通过。

### 2.2 资产负债表恒等式校验（C15）

```
资产总计 = 负债合计 + 所有者权益合计
```

- 容差：1 元；
- 差额 > 1 元 → FAIL，提示报表不平。

### 2.3 资产负债率校验

```
资产负债率 = 负债合计 / 资产总计
```

各产品阈值：
- AP：≤ 70%
- AK：≤ 75%（如有财报）
- AJ：≤ 80%
- AE：≤ 60%

## 三、参与的一致性校验

| 校验项 | 校验内容 |
|---|---|
| C1 企业名称一致性 | 报表名称与申请信息、其他材料比对 |
| C6 财报与纳税年度一致性 | 财报年度与纳税申报所属年度比对 |
| C9 材料日期时效 | 财报期间结束日不得晚于申请提交日 |
| C15 资产负债表恒等式 | 资产=负债+所有者权益 |

## 四、参与的准入规则

| 产品 | 规则编号 | 规则名称 |
|---|---|---|
| AP | AP-S02 | 资产负债率 ≤ 70% |
| AP | AP-S03 | 净利润为正 |
| AP | AP-S04 | 申请金额 ≤ 年营收 × 30% |
| AP | AP-S05 | 申请金额 ≤ 净资产 × 80% |
| AP | AP-S07 | 流水与财报货币资金差异 ≤ 20% |
| AK | AK-S06 | 财报资产负债率 ≤ 75% |
| AJ | AJ-S02 | 资产负债率 ≤ 80% |
| AJ | AJ-S04 | 申请金额 ≤ 年营收 × 40% |
| AJ | AJ-S05 | 净利润不为负 |
| AE | AE-S02 | 资产负债率 ≤ 60% |
| AE | AE-S04 | 申请金额 ≤ 年营收 × 50% |
| AE | AE-S05 | 净利润或经营现金流为正 |

## 五、常见问题与处置

| 问题 | 处置方式 |
|---|---|
| 资产总计出现多次（年初数/期末数） | 取最后一个值作为期末数 |
| 「流动负债合计」干扰「负债合计」识别 | 跳过前缀为「动」的匹配项 |
| 财报为合并报表，科目名称略有差异 | 按关键词模糊匹配，缺失则 uncertain |
| 三表分开上传 | 合并所有财务报表类材料的文本后统一校验 |
