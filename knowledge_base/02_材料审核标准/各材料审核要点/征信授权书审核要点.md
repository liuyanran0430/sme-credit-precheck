# 征信授权书审核要点

## 一、必填字段

| 字段名 | 说明 | 抽取方式 |
|---|---|---|
| 公司全称 | 授权主体名称 | 关键字「公司全称」后匹配 |
| 统一社会信用代码 | 18 位编码 | 关键字「统一社会信用代码」后匹配 |
| 法定代表人 | 自然人姓名 | 关键字「法定代表人」后匹配中文姓名 |
| 签署日期 | YYYY-MM-DD | 关键字「签署日期」后匹配中文日期 |
| 有效期至 | YYYY-MM-DD | 关键字「有效期自签署之日起至」后匹配中文日期 |

## 二、字段校验规则

### 2.1 授权时效校验（C7 + 强规则）

- **签署日期时效**：申请提交日 - 签署日期 ≤ 6 个月（186 天）；
- **授权有效期**：有效期至 ≥ 申请提交日；
- 任一不满足 → 授权书失效，需重新签署。

> 此规则同时作为强规则（AP-H04 / AK-H04 / AJ-H03 / AE-H04）和一致性校验项（C7）。

### 2.2 企业名称与信用代码校验

- 公司全称需与营业执照一致（C1）；
- 统一社会信用代码需与营业执照一致（C2）。

## 三、参与的一致性校验

| 校验项 | 校验内容 |
|---|---|
| C1 企业名称一致性 | 公司全称与申请信息、其他材料比对 |
| C2 统一社会信用代码一致性 | 信用代码与营业执照、纳税申报表比对 |
| C7 征信授权时效 | 签署日期 ≤ 6 个月且有效期未过 |
| C9 材料日期时效 | 签署日期不得晚于申请提交日 |

## 四、参与的准入规则

| 产品 | 规则编号 | 规则名称 |
|---|---|---|
| AP | AP-H04 | 征信授权书有效 |
| AK | AK-H04 | 征信授权书有效 |
| AJ | AJ-H03 | 征信授权书有效 |
| AE | AE-H04 | 征信授权书有效 |

## 五、常见问题与处置

| 问题 | 处置方式 |
|---|---|
| 授权书未标注有效期至 | 仅按签署日期 6 个月判断时效 |
| 签署日期识别异常 | C7 标记为 uncertain，转人工核验 |
| 授权书为个人授权（非企业） | 仍校验签署日期时效，企业名称比对跳过 |
| 授权书签署超过 6 个月 | 强规则 FAIL，直接拒绝 |
