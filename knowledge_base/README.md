# 信贷政策与材料审核知识库

> 版本：v2026-11-07
> 最后更新：2026-11-07

本知识库是小微企业授信智能预审系统的**业务知识单一事实来源**，涵盖信贷政策、材料审核标准、规则配置、案例与 FAQ 四大板块。

## 目录结构

```
knowledge_base/
├── 01_信贷政策/          # 产品准入规则、评分体系、结论口径
├── 02_材料审核标准/       # 分类标准、完整性要求、一致性校验、各材料审核要点
├── 03_规则配置/          # YAML 结构化规则源（后端直接读取，无需同步）
└── 04_案例与FAQ/         # 异常案例库、常见问题
```

## 与运行时规则的关系

- 本知识库 `03_规则配置/准入规则/` 下的 YAML 文件即为**运行时规则文件**，后端 `rule_config.py` 直接读取；
- `sme-credit-precheck-backend/rules/` 目录已删除，历史版本中仍需从该目录复制规则的情况已不再存在；
- 变更政策时，直接修改本知识库文件，运行 `scripts/validate_kb.py` 校验后重启后端生效。

## 维护指南

1. **编辑 Markdown**：面向业务人员，承载政策原文与说明；
2. **编辑 YAML**：面向机器加载，承载规则参数与阈值；
3. **校验**：运行 `scripts/validate_kb.py` 检查语法与口径一致性；
4. **生效**：规则文件由后端直接读取，校验通过后重启后端即可生效；
5. **重建索引**：运行 `scripts/rebuild_vector_index.py` 更新 RAG 向量库。

## 版本管理

- 知识库整体版本号 `vYYYY-MM-DD`，与规则文件 `version` 字段一致；
- 每条知识条目带 `created_at` / `updated_at` / `effective_date`；
- 历史版本通过 Git 回溯，历史报告通过 `ai_reports.rule_version` 关联。
